# Home Day Planner 🌈

A colourful after-school day planner for Shanvi. It shows what is happening now and what is coming next, lets her tick off each activity, and celebrates when the whole day is done.

**Live app:** https://swaroopnathgithub.github.io/Home_Day_Planner/

## Features
- Weekday, chess-class (Mon/Wed) and weekend schedules
- "Happening now" and "Coming up next" cards with a screen-time countdown
- Tick-off checklist with progress bar and a celebration at the end of the day
- Parent Edit mode to add, change or delete activities
- Week overview and a print-friendly view
- Everything is saved in the browser (localStorage), no account needed

## Deployment
A single static `index.html`, deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
